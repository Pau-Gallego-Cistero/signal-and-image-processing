# 📚 Signal and Image Processing: Coursework & Labs

This directory contains laboratory scripts, exercises, and algorithm implementations developed throughout my **Signal and Image Processing** course at Universidad Europea de Valencia (Fall 2026).

---

## Course Objectives
* Study discrete signals, sampling theorems, and time/frequency representations.
* Implement 1D signal filters (Butterworth, Chebyshev, moving average) and noise reduction.
* Explore 2D spatial filtering, edge detection, and morphological transformations on images.
* Apply practical algorithms using mainly **Python**.
